# Capturas do README

As imagens da mesa e da carta foram capturadas na visão do jogador do adaptador local, com os recursos do módulo. Na captura da carta, o painel de profecia foi ocultado apenas para a imagem.

`previews/tarokka-player-dice-so-nice.png` usa o renderizador DiceBox, os materiais e a simulação física do Dice So Nice! 5.3.4 instalado localmente, em uma área de rolagem sobre a mesa do adaptador. Mostra dois dados percentuais durante a animação. O código do Dice So Nice não é incluído no repositório nem no ZIP do Tarokka.

Essa captura demonstra a aparência dos dados; não substitui a validação da integração em um mundo Foundry.
